# 텔레그램 리포트 기획 문서

## 📋 개요

비즈액터스쿨 주간 광고 성과를 텔레그램으로 자동 발송하는 리포트 양식 설계

---

## 🎯 리포트 목적

1. **의사결정 지원**: 광고 성과를 한눈에 파악하여 빠른 의사결정
2. **트렌드 파악**: 주간 단위 성과 변화 추이 확인
3. **액션 유도**: 개선이 필요한 광고 식별 및 조치 가이드
4. **상세 분석 연결**: 대시보드 링크로 심층 분석 유도

---

## 📱 리포트 구조

### 1. 헤더 (Header)
```
📊 [BAS] {클라이언트명} 주간 리포트
📅 {시작일} ~ {종료일}
━━━━━━━━━━━━━━━━━━━━━━
```

**포함 정보**:
- 클라이언트명
- 리포트 기간 (YYYY-MM-DD 형식)
- 구분선

---

### 2. 핵심 성과 요약 (Executive Summary)
```
📈 핵심 성과

💰 총 지출: ${xxx.xx}
🎯 총 리드: {xx}건
💵 평균 CPL: ${xx.xx}
📊 평균 CTR: {x.xx}%

👁️ 노출수: {x,xxx}회
👆 클릭수: {xxx}회
```

**포함 지표**:
- 총 지출 (Total Spend)
- 총 리드 (Total Leads)
- 평균 CPL (Average Cost Per Lead)
- 평균 CTR (Click Through Rate)
- 총 노출수 (Impressions)
- 총 클릭수 (Clicks)

**아이콘 의미**:
- 💰 지출
- 🎯 리드/전환
- 💵 비용 효율성
- 📊 참여율
- 👁️ 도달
- 👆 행동

---

### 3. 전주 대비 증감률 (Week-over-Week Comparison)
```
📊 전주 대비 변화

리드: ▲ 15.3% ⬆️
CPL: ▼ 8.2% ⬇️ 개선!
지출: ▲ 5.1%
CTR: ▼ 2.3%
```

**포함 정보**:
- 주요 지표별 증감률
- 증가/감소 화살표 (▲/▼)
- 긍정적 변화 강조 (⬆️/⬇️)
- "개선!" 태그

**조건부 표시**:
- CPL 감소 → "⬇️ 개선!"
- 리드 증가 → "⬆️ 성장!"
- CPL 급증 (>20%) → "⚠️ 주의 필요"
- 리드 급감 (>20%) → "🔴 점검 필요"

---

### 4. AI 인사이트 (AI-Powered Insights)
```
💡 이번 주 인사이트

• CPL이 8.2% 감소하여 비용 효율성이 개선되었습니다
• 리드가 15.3% 증가하여 전환이 크게 개선되었습니다
• "고객이찾아오는영업" 광고가 가장 효율적입니다 (CPL: $13.09)
• "삶이불안막막하다면" 광고는 개선이 필요합니다 (CPL: $53.49)
```

**자동 생성 로직**:
1. CPL 변화 분석
2. 리드 변화 분석
3. Best 광고 강조
4. Worst 광고 주의 환기
5. CTR 트렌드 분석

### 5. 광고별 성과 순위 (Ad Performance Ranking)

#### 5.1 Best Performing 광고
```
🏆 Best Performing 광고 (TOP 5)

   💵 CPL: $13.09 | 📊 CTR: 2.50% | 🎯 리드: 2건

2. 법인영업에지친당신
   💵 CPL: $21.69 | 📊 CTR: 2.33% | 🎯 리드: 5건

3. ...
```

**정렬 기준**: CPL 낮은 순 (비용 효율성)
**표시 개수**: TOP 5
**포함 정보**:
- 광고명 (20자 초과 시 "..." 처리)
- CPL
- CTR
- 리드 수

#### 5.2 Needs Improvement 광고
```
⚠️ 개선 필요 광고 (BOTTOM 3)

1. 삶이불안막막하다면
   💵 CPL: $53.49 | 📊 CTR: 2.10% | 🎯 리드: 1건
   ⚡️ 액션: 광고 소재 교체 또는 타겟팅 재설정 권장

2. ...
```

**조건**: 전체 광고 5개 이상일 때만 표시
**정렬 기준**: CPL 높은 순
**표시 개수**: BOTTOM 3
**추가 정보**: 개선 액션 가이드

### 7. 추천 액션 (Recommended Actions)
```
🎯 이번 주 추천 액션

1. ✅ "고객이찾아오는영업" 광고 예산 20% 증액 고려
2. ⚠️ "삶이불안막막하다면" 광고 크리에이티브 A/B 테스트
3. 📊 CTR이 높은 "법인영업에지친당신" 광고 확대 추천
```

**생성 조건**:
- Best 광고 (CPL < 평균) → 예산 증액 권장
- Worst 광고 (CPL > 평균 150%) → 개선 권장
- CTR 높음 (>2.5%) → 확대 권장
- 리드 급감 → 원인 분석 필요
