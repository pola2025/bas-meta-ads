## 2. 주요 디자인 요소

### 2.1 이모지 규칙

| 용도 | 이모지 | 설명 |
|------|--------|------|
| 상승 | 🟢⬆️ | 전월 대비 증가 |
| 하락 | 🔴⬇️ | 전월 대비 감소 |
| 게이지바 | 🟩 | 최대값 기준 비율 (최대 10개) |
| 효율적 | ✅ | 리드% > 지출% + 5% |
| 검토필요 | ⚠️ | 리드% < 지출% - 5% |
| 보통 | 📊 | 그 외 |

### 2.2 게이지바 로직

```javascript
// 최대값 기준 비율로 표시
function generateEmojiBar(value, maxValue, maxBars = 10) {
  const ratio = value / maxValue;
  const bars = Math.max(1, Math.round(ratio * maxBars));
  return '🟩'.repeat(bars);
}

// 예시: 최대 45건일 때
// 45건 → 🟩🟩🟩🟩🟩🟩🟩🟩🟩🟩 (10개)
// 29건 → 🟩🟩🟩🟩🟩🟩🟩 (7개)
// 8건 → 🟩🟩 (2개)
```

### 2.3 변화율 표시

```javascript
// 상승/하락 이모지 + 퍼센트
function calculateChange(current, previous) {
  const change = ((current - previous) / previous) * 100;
  const emoji = change >= 0 ? '🟢⬆️' : '🔴⬇️';
  const sign = change >= 0 ? '+' : '';
  return `${emoji} ${sign}${change.toFixed(1)}%`;
}
```

## 4. 데이터 저장

### 4.1 테이블: `telegram_reports`

| 필드 | 타입 | 설명 |
|------|------|------|
| id | UUID | Primary Key |
| client_id | UUID | 클라이언트 ID |
| week_start | DATE | 월 시작일 (ex: 2025-10-01) |
| week_end | DATE | 월 종료일 (ex: 2025-10-31) |
| report_type | VARCHAR | 'monthly' |
| message_text | TEXT | 4개 메시지 합본 |
| report_data | JSONB | 구조화된 데이터 |
| ai_insights | TEXT | AI 인사이트 |
| sent_at | TIMESTAMP | 발송 시각 |

// 동일 기간 리포트가 있으면 UPDATE, 없으면 INSERT
