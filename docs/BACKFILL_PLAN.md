## ⏱️ Rate Limit 정보

### Meta API Rate Limit
- **타입**: Application-level rate limiting (슬라이딩 윈도우)
- **제한**: 약 200 calls/hour per user
- **리셋 방식**: **Rolling Hour** - 1시간 윈도우 내 호출 수 추적
- **현재 상태**: 제한 걸림 (2025-11-25 16:07 KST 기준)

### 슬라이딩 윈도우 동작 방식
```
[시간] ─────────────────────────────────────────────────────►
       │← ─ ─ ─ ─ ─ ─ 1시간 윈도우 ─ ─ ─ ─ ─ ─ →│

16:00  │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ 200 calls (한도 초과)
16:30  │────────────────────▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ 150 calls (일부 여유)
17:00  │────────────────────────────────────│ 0 calls (완전 회복)
```

- **점진적 회복**: 1시간 전 호출이 하나씩 윈도우에서 빠지면서 여유 생김
- **완전 회복**: 마지막 대량 호출로부터 약 1시간 후
- **부분 회복**: 15-45분 후부터 소량 호출 가능

### 예상 대기 시간
- **부분 회복 예상**: 2025-11-25 16:30~16:45 KST (소규모 배치 가능)
- **완전 회복 예상**: 2025-11-25 17:10 KST
- **전체 백필 예상 소요**: 각 배치당 1-2분, 총 10-15분

### Response Header 모니터링
백필 스크립트에서 다음 헤더를 확인하면 Rate Limit 상태 파악 가능:
- `x-business-use-case-usage`
- `x-app-usage`
- `x-ad-account-usage`
- `x-fb-ads-insights-throttle`
