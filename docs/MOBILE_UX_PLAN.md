## 1. 개요 탭 (Overview)

### 현재 문제점
- 플랫폼별 차트가 모바일에서 너무 작음
- 트렌드 차트 레이블 겹침
- 차트 간 구분 어려움

### 모바일 개선안

#### 1-1. 아코디언 레이아웃 (기본 상태 정의)

> ⚠️ **피드백 반영**: 모든 아코디언이 닫혀 있으면 첫 화면에서 정보를 얻지 못함
> **개선**: 📈 일별 트렌드는 기본 '펼침', 나머지는 '접힘' 상태로 시작

```
┌─────────────────────────────┐
│ 📈 일별 트렌드          [▼] │  ← 기본 펼침 (Open)
├─────────────────────────────┤
│  [선택 날짜: 11/24]         │  ← Scrubbing 헤더
│  리드 12건 | 지출 $180      │
│  ┌─────────────────────┐    │
│  │   라인 차트          │    │
│  │   (180px 높이)       │    │
│  │   --- 최대값 표시    │    │
│  │                     │    │
│  │   --- 최소값 표시    │    │
│  └─────────────────────┘    │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 📊 플랫폼별 성과        [▶] │  ← 기본 접힘 (Closed)
└─────────────────────────────┘

┌─────────────────────────────┐
│ 🎯 CPL 추이             [▶] │  ← 기본 접힘 (Closed)
└─────────────────────────────┘
```

#### 1-2. 차트 인터랙션 개선

> ⚠️ **피드백 반영**: 터치 시 툴팁은 손가락에 가려 안 보임
> **개선**: Scrubbing 방식 - 터치한 날짜 데이터를 차트 상단 헤더에 고정 표시

**일별 트렌드 (TrendChart)**
```tsx
// 차트 상단에 선택된 날짜 정보 표시
<div className="text-center mb-2 text-sm">
  <span className="font-semibold">{selectedDate}</span>
  <span className="text-blue-600 ml-2">리드 {leads}건</span>
  <span className="text-gray-500 ml-2">지출 ${spend}</span>
</div>
```

#### 1-3. 축(Axis) 처리

> ⚠️ **피드백 반영**: Y축 완전 숨김 시 데이터 규모 파악 어려움
> **개선**: 최대값/최소값 점선 표시 + 배경 그리드 2개만 유지

```
┌─────────────────────────────┐
│ ─ ─ ─ ─ ─ ─ ─ 최대 45건 ─ ─│  ← 점선 + 우측 레이블
│     ╭──╮                    │
│    ╭╯  ╰╮   ╭─╮            │
│ ─ ─ ─ ─ ─ ─ 평균 30건 ─ ─ ─│  ← 중간 그리드
│   ╭╯     ╰──╯  ╰╮          │
│ ─ ─ ─ ─ ─ ─ ─ 최소 15건 ─ ─│  ← 점선 + 우측 레이블
└─────────────────────────────┘
```

**차트별 최적화**

| 차트 | 높이 | X축 레이블 | Y축 | 표시 선 |
|------|------|-----------|-----|--------|
| 일별 트렌드 | 180px | 3일 간격 | 최대/최소 점선 | 리드, 지출 (2개) |
| 플랫폼별 | 150px | - | - | 도넛 + 가로 바 |
| CPL 추이 | 160px | 날짜 | 평균선 | 최근 7일 |

## 2. 기간별 데이터 탭 (Period Data)

### 현재 문제점
- 테이블 가로 스크롤 필요
- 숫자 밀도 높음
- 중요 지표 파악 어려움
- 전기간 대비 비교 없음

### 모바일 개선안

#### 2-1. 카드 리스트 형태 (증감률 추가)

> ⚠️ **피드백 반영**: 단순 수치만으로는 성과 판단 어려움
> **개선**: 카드 우측 상단에 전기간 대비 증감률 표시

```
┌─────────────────────────────┐
│ 2024년 11월           ▴5.2% │  ← 전월 대비 리드 증감
│                             │
│  CPL $15.23  ← 큰 강조      │
│                             │
│  ┌────┐ ┌────┐ ┌────┐      │
│  │리드│ │지출│ │CTR │      │
│  │ 45 │ │$2K │ │2.5%│      │
│  └────┘ └────┘ └────┘      │
└─────────────────────────────┘
```

#### 2-2. 일별 리스트 2줄 레이아웃

> ⚠️ **피드백 반영**: 4개 정보 한 줄에 넣으면 작은 화면에서 꽉 참
> **개선**: 2줄 레이아웃으로 가독성 확보

```
┌─────────────────────────────┐
│ 11/24 (월)        CPL $15.23│  ← 1줄: 날짜 + CPL (강조)
│ 리드 45건 | 지출 $180       │  ← 2줄: 상세 지표
├─────────────────────────────┤
│ 11/23 (일)        CPL $18.50│
│ 리드 38건 | 지출 $210       │
└─────────────────────────────┘
```

#### 2-3. 뷰 모드별 표시
- **월별**: 월간 요약 카드 (증감률 포함)
- **주별**: 주간 요약 카드 (증감률 포함)
- **일별**: 2줄 레이아웃 리스트

## 3. 광고별 상세 탭 (Ads Detail)

### 현재 문제점
- 10개 칼럼 → 가로 스크롤 필수
- 광고명 잘림
- 비활성 광고 구분 어려움

### 모바일 개선안

#### 3-1. 카드형 리스트 (배경색 구분)

> ⚠️ **피드백 반영**: 비활성 광고를 흐리게만 처리하면 시인성 부족
> **개선**: 비활성 카드 배경색 `bg-gray-50`, 활성 카드 `bg-white`

```
┌─────────────────────────────┐  ← bg-white (활성)
│ 1 🟢 광고명_어쩌구...  11/24│
│    캠페인명...              │
│                             │
│ ████████████░░░░░░  12건    │
│                             │
│ ┌────┐ ┌────┐ ┌────┐       │
│ │지출│ │CPL │ │CTR │       │
│ │$180│ │$15 │ │2.3%│       │
│ │    │ │ ✅ │ │    │       │
│ └────┘ └────┘ └────┘       │
│                             │
│ [탭하면 제자리 확장]        │
│ ┌────┐ ┌────┐ ┌────┐       │
│ │노출│ │클릭│ │CVR │       │
│ │25K │ │580 │ │2.1%│       │
│ └────┘ └────┘ └────┘       │
└─────────────────────────────┘

┌─────────────────────────────┐  ← bg-gray-50 (비활성)
│ 2 ⚪ 비활성광고...     11/20│
│    ...                      │
└─────────────────────────────┘
```

#### 3-2. 인터랙션 (스와이프 제거)

> ⚠️ **피드백 반영**: 세로 스크롤 리스트에서 좌우 스와이프는 제스처 충돌 위험
> **개선**: 스와이프 기능 제외, 탭하여 제자리 확장에 집중

**기능**
- **탭하면 확장**: 추가 지표 (노출, 클릭, CVR) 제자리 표시
- ~~좌우 스와이프~~: 제거
- **상단 필터**: 활성/비활성 토글

#### 3-3. 확장 애니메이션

```tsx
// 부드러운 확장 애니메이션
<div className={`
  overflow-hidden transition-all duration-200 ease-in-out
  ${isExpanded ? 'max-h-40 opacity-100' : 'max-h-0 opacity-0'}
`}>
  {/* 추가 지표 */}
</div>
```

## 4. 공통 디자인 가이드

### 4-1. 컬러 시스템

| 용도 | 색상 | 라이트 모드 | 다크 모드 (향후) |
|------|------|------------|-----------------|
| CPL 양호 | 녹색 | `text-green-600`, `bg-green-50` | `text-green-400`, `bg-green-900/20` |
| CPL 경고 | 주황색 | `text-orange-600`, `bg-orange-50` | `text-orange-400`, `bg-orange-900/20` |
| 활성 광고 | 녹색 점 | `fill-green-500` | `fill-green-400` |
| 비활성 광고 | 회색 배경 | `bg-gray-50` | `bg-gray-800` |
| 리드 프로그레스 | 에메랄드 | `bg-emerald-500` | `bg-emerald-400` |

### 4-2. 타이포그래피

> ⚠️ **피드백 반영**: `text-[10px]`은 접근성 이슈 (읽기 어려움)
> **개선**: 최소 폰트 사이즈 11px, 덜 중요한 정보는 색상으로 위계 구분

| 요소 | 모바일 | PC | 비고 |
|------|--------|-----|------|
| 섹션 타이틀 | `text-base` (16px) | `text-lg` (18px) | |
| 카드 숫자 (강조) | `text-lg` (18px) | `text-3xl` (30px) | |
| 카드 숫자 (보조) | `text-sm` (14px) | `text-sm` (14px) | |
| 레이블 | `text-xs` (12px) | `text-xs` (12px) | ~~text-[10px]~~ 제거 |
| 보조 텍스트 | `text-xs text-gray-400` | `text-xs text-gray-400` | 색상으로 위계 구분 |
| 본문 | `text-xs` (12px) | `text-sm` (14px) | |

### 4-3. 간격

| 요소 | 모바일 | PC |
|------|--------|-----|
| 카드 패딩 | `p-3` (12px) | `p-6` (24px) |
| 그리드 갭 | `gap-2` (8px) | `gap-4` (16px) |
| 섹션 마진 | `mt-4` (16px) | `mt-6` (24px) |

### 4-4. 터치 영역
- 최소 터치 영역: 44x44px
- 버튼/탭 패딩: `py-2 px-3` 이상

## 6. 검증 체크리스트

### 가독성
- [ ] 모든 텍스트가 잘림 없이 표시되는가?
- [ ] 숫자가 명확하게 구분되는가?
- [ ] CPL 상태 (양호/경고)가 직관적인가?
- [ ] **최소 폰트가 12px 이상인가?** (접근성)

### 시각화
- [ ] 차트가 충분히 크게 보이는가?
- [ ] 프로그레스 바가 비율을 잘 표현하는가?
- [ ] 활성/비활성 구분이 명확한가? (배경색 차이)
- [ ] **Y축 없이도 데이터 규모를 파악할 수 있는가?**

### 인터랙션
- [ ] 터치 영역이 충분한가? (44px)
- [ ] 탭 전환이 부드러운가?
- [ ] 확장/축소가 자연스러운가? (200ms)
- [ ] **제스처 충돌이 없는가?** (스와이프 제거)

### 데이터 밀도
- [ ] 큰 숫자 ($1,234,567) 표시 시 레이아웃 깨지지 않는가?
- [ ] 작은 숫자 (0, 1) 표시 시 레이아웃 깨지지 않는가?
- [ ] 긴 광고명 truncate 처리되는가?

### 성능
- [ ] 첫 로딩이 3초 이내인가?
- [ ] 스크롤이 부드러운가?
- [ ] 애니메이션이 60fps인가?

## 7. 최종 점검 포인트 (Polish)

### 7-1. Sticky Header (스크롤 시 헤더 고정)

> ⚠️ **피드백**: 광고 50개+ 리스트에서 스크롤 내리면 필터/정렬 옵션이 사라져 불편

**적용 대상**
- 광고별 상세 탭: 정렬 옵션 (CPL/리드/지출)
- 기간별 데이터 탭: 뷰 모드 선택 (일별/주별/월별)

**구현**
```tsx
// 헤더 고정
<div className="sticky top-0 z-10 bg-white border-b border-gray-200">
  {/* 정렬/필터 옵션 */}
</div>
```

### 7-2. 카드 확장 트리거 영역

> ⚠️ **피드백**: 카드 전체를 눌러야 할지, 특정 버튼을 눌러야 할지 명확히

**결정**: 카드 전체 영역을 터치 영역으로 설정 (모바일 편의성)

**예외 처리**: 카드 내 별도 링크가 있으면 `e.stopPropagation()` 처리
```tsx
<div onClick={() => setExpanded(!expanded)}>
  {/* 카드 내용 */}
  <a
    href="/ad-manager"
    onClick={(e) => e.stopPropagation()}  // 확장 이벤트 방지
  >
    광고 관리자 바로가기
  </a>
</div>
```

### 7-3. 빈 상태 (Empty State) 처리

> ⚠️ **피드백**: 데이터가 없을 때 빈 화면 대신 친절한 안내 필요

**디자인**
```
┌─────────────────────────────┐
│                             │
│      📊 (회색 아이콘)        │
│                             │
│  선택한 기간에 데이터가      │
│  없습니다.                  │
│                             │
│  [기간 변경하기] (옵션)      │
│                             │
└─────────────────────────────┘
```

**문구 예시**
| 상황 | 문구 |
|------|------|
| 기간 필터 결과 없음 | "선택한 기간에 데이터가 없습니다." |
| 신규 캠페인 | "아직 집행된 광고가 없습니다." |
| 비활성 광고만 숨김 | "활성 광고가 없습니다. '비활성 광고 표시'를 켜보세요." |

**구현**
```tsx
{data.length === 0 && (
  <div className="flex flex-col items-center justify-center py-12 text-gray-400">
    <Calendar className="w-12 h-12 mb-3 opacity-50" />
    <p className="text-sm">선택한 기간에 데이터가 없습니다.</p>
  </div>
)}
```
